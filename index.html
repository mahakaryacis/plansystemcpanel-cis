1. Akses Repositori (GitHub)

Pintu Masuk Brankas Kode

Seluruh sistem aplikasi CIS Protocol dibangun dan disimpan di dalam platform GitHub. Sebelum Anda bisa melakukan *update* teks, memperbaiki *bug*, atau melakukan rilis versi terbaru, Anda harus masuk ke Repositori yang tepat.

Memilih Repository (Top Repositories)

Setelah login ke akun GitHub Mahakarya CIS, perhatikan panel menu di sebelah kiri layar Anda. Di sana terdapat kotak bertuliskan "Top repositories".

Langkah Pemilihan Kode:

  • 1
    Akses Dasbor Utama: Pastikan Anda sudah login dan berada di halaman beranda (Home) GitHub.
  • 2
    Pilih Modul Publik: Jika Anda ingin mengedit tampilan untuk Miner (Web Penambang), klik repositori bernama mahakaryacis/cismining-app.
  • 3
    Pilih Modul Master: Jika Anda ingin merubah sistem Admin Panel atau C-Panel, klik repositori bernama mahakaryacis/markascis-app.

2. Membuat & Menamai File

Mengisi Kolom "Name your file..."

Ini adalah langkah untuk mendefinisikan halaman website Anda. Kolom "Name your file..." WAJIB diisi dengan nama beserta format ekstensinya agar sistem mengenali jenis kodenya sebagai halaman web.

Format Penamaan File HTML

Jika Anda sedang memasukkan kode untuk tampilan website (seperti UI Dashboard atau Manual Book), Anda harus menggunakan akhiran ekstensi .html tanpa spasi.

Panduan Pengisian:

  • 1
    Halaman Utama: Jika ini adalah halaman muka dari website tersebut, ketikkan index.html.
  • 2
    Halaman Spesifik: Jika ini adalah halaman fungsi khusus (seperti panel admin), Anda bisa menamainya sesuai fungsinya, contoh: admin.html atau dashboard.html.
  • 3
    Isi Kode (Konten): Setelah nama file dipastikan benar, letakkan kursor di kotak besar berwarna putih bertuliskan "Enter file contents here", lalu Paste (tempel) seluruh skrip kode Anda di sana.
