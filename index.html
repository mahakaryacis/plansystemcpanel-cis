1. Akses Repositori (GitHub)

Pintu Masuk Brankas Kode

Seluruh sistem aplikasi CIS Protocol dibangun dan disimpan di dalam platform GitHub. Sebelum Anda bisa melakukan pembaruan web, Anda harus masuk ke repositori yang tepat.

  • 1
    Akses Dasbor Utama: Pastikan Anda login di GitHub.
  • 2
    Pilih Modul Publik: Untuk mengubah Web Penambang, klik repositori mahakaryacis/cismining-app.
  • 3
    Pilih Modul Master: Untuk mengubah sistem Admin Panel, klik repositori mahakaryacis/markascis-app.

2. Membuat & Menamai File

Mengisi Kolom "Name your file..."

Kolom "Name your file..." WAJIB diisi dengan nama beserta format ekstensinya agar sistem GitHub mengenalinya sebagai halaman website.

  • 1
    Halaman Utama: Jika ini halaman muka (Home), ketikkan index.html.
  • 2
    Halaman Spesifik: Untuk halaman khusus, Anda bisa menamainya sesuai fungsi, contoh: admin.html.
  • 3
    Isi Kode (Konten): Tempel (*paste*) seluruh skrip kode ke dalam kotak besar berwarna putih.

3. Dasbor & Live Monitor

Hak Akses Administrator

Aplikasi Command V2 ini dilindungi oleh Login Terenkripsi. Terdapat 2 tingkat peran Admin:

  • MASTER (Super Admin): Memiliki akses absolut ke semua 12 Menu dan berhak melakukan Factory Reset.
  • CPANEL (Asisten): Hanya bisa melihat menu-menu tertentu yang sudah diizinkan (dicentang) oleh Master di menu "Manajemen C-Panel".

Membaca Live Monitor

Menu Live Monitor adalah radar pusat yang tersinkronisasi per detik. Di sini Anda bisa memantau siapa saja Miner yang berstatus Online (sedang menghidupkan mesin) vs Offline. Sistem juga akan otomatis mengkalkulasi beban perputaran koin (Omset Global) mulai dari hitungan Detik hingga ke beban 30 Hari ke depan.

4. Keuangan & Pabrik Token

Manajemen Ekonomi Ekosistem

Perputaran ekonomi CIS dikontrol ketat melalui persetujuan Withdraw dan pencetakan Token.

  • Pabrik Token: Master dapat memproduksi Token Aktivasi (REG) dan Token Speed (MINING) secara tak terbatas tanpa modal. Anda bisa mendistribusikannya ke Tim Grosir, atau mengirimkannya langsung (Injeksi) ke email 1 Pemain spesifik.
  • Persetujuan WD: Anda bisa menyetujui pengajuan WD satu per satu, atau mencentang banyak WD sekaligus lalu klik "Setujui Otomatis (Terpilih)". Jika Anda menolak WD, saldo Rupiah Miner akan otomatis dikembalikan (Refund).
  • Mode Auto WD: Di menu Persetujuan WD, terdapat sakelar Mode WD Otomatis. Jika dihidupkan, setiap Miner yang WD tidak perlu antre; sistem langsung mencetakkan token detiknya itu juga!

5. Kontrol Miner (Fitur Dewa)

Otoritas Pengendalian Akun

Masuk ke menu Data Miner. Di sini Admin memiliki kuasa absolut atas semua partisipan.

Edit Data Dewa

Klik tombol biru "Edit" pada tabel user. Muncul form yang mengizinkan Admin untuk secara gaib mengubah Saldo VRSC, Saldo Rupiah, masa expired, Speed Hash, hingga mengubah Password & 6-Digit PIN Transaksi milik Miner tersebut tanpa persetujuan mereka.

  • Lacak Perangkat (Track): Klik tombol "Lacak". Sistem akan menampilkan Sistem Operasi (Android/iOS/PC), Alamat IP (Internet), Lokasi Negara/Kota, dan Provider Internet dari user tersebut.
  • Unlock Device: Jika akun user nyangkut karena ganti HP (Kena Device Lock), Anda bisa mereset kuncinya dari tombol paling atas "UNLOCK DEVICE USER" atau klik "Terkunci (Reset)" di baris tabel user.

EKSEKUSI MASTER RESET

Terletak di bagian paling bawah Data Miner. Jika dieksekusi, fitur ini akan MENGHANCURKAN SELURUH DATABASE PENGGUNA. Semua saldo, transaksi, dan riwayat akan musnah, dan sistem kembali ke pengaturan pabrik (0 Hari).

6. Sistem & Pengumuman

Mengendalikan Status Web & Event

Menu Sistem & Game dan Pengumuman dipakai untuk berinteraksi massal dengan Miner.

  • Mode Maintenance & Hitung Mundur: Jika dihidupkan, tampilan login user akan terkunci total dan digantikan oleh Animasi Perbaikan Web atau Hitung Mundur (Countdown) menuju peluncuran. Mode ini akan otomatis mati (Web terbuka lagi) saat waktu 'Target Launch' tersentuh.
  • Setting Reward 1 Jam: Di menu Sistem & Game, Anda bisa mengubah berapa "Coin" yang dihasilkan tombol klaim setiap jamnya, termasuk mengatur Happy Hour (jam khusus dengan bonus ekstra).
  • Banner Event Promosi: Di menu Pengumuman, Anda dapat menghidupkan Kotak Banner Promo yang akan muncul di atas tombol Claim pengguna. Anda bisa mengatur bonus koin atau bonus kecepatan langsung dari sana.
